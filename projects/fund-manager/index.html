使用说明

本工具是管理员个人使用的活动经费记账与催办助手，不是正式财务系统。

重要：业务数据只保存在当前浏览器本地。更换电脑、清理网站数据或重置浏览器都可能导致数据不可访问，请优先阅读下方“本地数据与备份”并定期执行完整备份。
本地数据与备份（必读）快速开始预算导入活动管理报销催办隐私模式备份恢复统计导出
请先确认你理解本地数据的风险本工具没有网络数据库。浏览器里的数据一旦被清理，网页本身无法从服务器替你恢复。

一、本地数据与备份（必读）

  • 业务数据只保存在当前浏览器本地，不会上传到网络数据库。
  • 更换电脑、清理浏览器网站数据、重置浏览器配置或浏览器故障，都可能使本地数据无法继续访问。
  • 建议定期点击“完整备份”下载电子表格工作簿，并把备份文件保存到可靠位置。
  • 执行完整恢复前，系统会先要求保存一份“恢复前自动备份”，用于误恢复后的回退。
  • 本工具不保存修改历史，只保存当前值和各可编辑单元格的最后编辑日期。
  • 金额以人民币元显示，最多两位小数；内部按“分”的整数计算。预算、预支、单价和总价不接受负数；经费差额可以为负数。

二、快速开始

  1. 在首页点击“新建活动”，只填写活动名称；或者从预算电子表格直接创建活动。
  2. 活动编号自动取现有最大编号加 1；创建日期自动取电脑当天日期。
  3. 新活动的预支金额默认为 0.00，首页状态显示“未预支”。实际发生预支后，进入活动详情修改“预支金额”。
  4. 学生报销时，在支出清单中核对实际金额并勾选“已报销”。系统自动累计已报销金额并计算经费差额。
  5. 遇到无法由金额自动表达、但管理员已经线下处理完成的情况，可勾选“经费已手动处理”，停止该活动催办。
经费差额 = 预支金额 − 已报销金额。正数表示仍有预支经费需要追踪；负数表示已报销金额超过预支金额，需要更多经费。

三、普通预算电子表格导入

普通预算导入只识别以下四个表头，名称必须准确：

模板直接由当前网页生成，工作表顶部自带填写说明和示例，不需要另外查看说明书。
活动物品单价总价

  • 不再兼容旧表头名称。
  • “活动”单元格可以留空。空着时，自动继承上方最近一个非空活动名称。
  • “单价”可以留空；留空后活动详情中也保持为空。
  • “总价”是预算汇总与报销汇总真正使用的金额字段。
  • 普通预算表不导入“备注”。导入后每条支出的备注默认为空，可在活动详情中手动填写。
  • 同一个文件可以包含多个活动，系统会按活动名称分组；导入预览时可以选择“新建活动”或“追加到现有活动”。

普通预算导入新活动时，预算金额初始化为该活动所有“总价”的合计；预支金额初始化为 0.00。

四、活动查看与批量管理

主页查看与筛选

主页每个活动对应一张活动卡片。可以按活动名称或编号搜索，也可以选择“仅未结清”，并按照创建日期设置开始和结束日期。状态筛选、时间筛选和搜索可以组合使用。

“未结清”包括未预支、待追缴和需追加经费的活动，不包括已结清或已手动处理的活动。

活动管理已经集中到主页

  1. 点击主页工具栏中的“活动管理”。普通模式下需要先输入密码；秘密模式下可直接进入。
  2. 进入活动管理后，每张活动卡片会出现选择框。可以逐个勾选，也可以点击“全选当前结果”，一次选择当前搜索和筛选结果中的所有活动。
  3. “清空选择”会取消全部已选活动；管理条会始终显示当前已选活动数量。
  4. 点击“导出选中”，会生成适合人工阅读的电子表格工作簿：第一张为“选中活动总览”，之后每个选中活动各一张工作表。
  5. 点击“删除选中”会先显示二次确认；确认后一次删除所有选中活动及其支出数据。删除没有回收站。
  6. 点击“完成管理”退出批量管理，活动卡片恢复为点击进入详情的正常行为。
“全选当前结果”只会增加当前筛选结果中的活动。已经选择但后来被筛选隐藏的活动仍保持选中，应以“已选 X 个活动”的数量为准；需要重新开始时点击“清空选择”。

单个活动详情

点击活动卡片进入该活动的子界面。活动详情只负责编辑这个活动自身的数据和支出，不再承担删除整个活动的操作。

  • 活动总体信息包括活动名称、创建日期、预算金额、预支金额、已报销金额、经费差额和“经费已手动处理”状态。预算主要用于判断是否发生超支。
  • 预算金额在导入时初始取支出总价之和，之后成为独立可编辑字段，不会因为后续修改支出自动变化。当已报销金额超过预算金额时，首页会显示“超出预算”及超出金额；未超出时显示预算剩余。
  • 预支金额只保存当前总值，不记录多次预支历史；需要追加预支时直接修改该值。
  • 已报销金额由所有已勾选支出的“总价”自动求和，不能直接编辑。
  • 每个可编辑单元格下方都会显示该单元格自己的最后编辑日期。

支出清单

每条支出包含“物品、单价、总价、备注、已报销、报销日期”。可以新增、编辑或直接删除单条支出。删除单条支出不二次确认。

系统不记录数量，也不支持单条支出“部分报销”。如果实际可报销金额发生变化，应先修改该条支出的总价，再勾选已报销。

五、报销操作

  1. 进入对应活动详情，找到实际已经报销的支出。
  2. 如实际金额与原预算不同，先修改“总价”。
  3. 勾选“已报销”。系统立即把这条支出的总价计入已报销金额，并自动记录当天为报销日期。
  4. 取消“已报销”时，原报销日期自动清空；以后再次勾选时，日期改为再次勾选的当天。

报销日期由系统自动维护，不允许手工修改。

六、催办规则

网页每次首次打开或刷新时，都会读取电脑当天日期并重新判断全部活动。

一个活动只有同时满足以下条件，才会进入催办：

  • 预支金额大于 0；
  • 未勾选“经费已手动处理”；
  • 预支金额 − 已报销金额不等于 0；
  • 从活动创建日期起已经满一个自然月。

一旦进入催办期，此后每次打开或刷新都会继续提醒，直到差额变为 0 或管理员勾选“经费已手动处理”。如果存在待催办活动，首次加载时会弹窗提示活动数量，具体活动列在首页“催办提醒”区域。

预支金额为 0 的活动显示“未预支”，不会进入催办。给活动填写实际预支金额后，系统才把它纳入催办判断。

七、普通模式、活动详情与秘密模式

  • 普通模式主页：金额统一打码，适合学生在旁边时查看活动列表和状态。
  • 普通模式进入活动：需要输入密码。验证成功后，仅本次活动详情显示真实金额；返回首页后，主页继续打码。
  • 秘密模式：输入密码进入后，主页显示真实金额，进入活动详情不再重复验证。
  • 刷新：刷新页面后恢复普通模式，避免下次打开页面时直接暴露金额。

说明书不会展示实际密码。密码校验用于日常屏幕隐私保护，不等同于专业的数据加密系统。

八、完整备份与恢复

完整备份

点击“完整备份”会生成一个电子表格工作簿，其中包含一个“总览”工作表，以及每个活动各自的“活动_编号”工作表。完整备份会保存活动状态、支出、备注、报销日期和每个可编辑字段的最后编辑日期。

完整恢复

通过“导入工作簿”选择本工具生成的完整备份文件。恢复采用整体覆盖方式，不与当前数据自动合并。

真正覆盖当前数据以前，系统会先要求把当前状态另存为一份安全备份。如果用户取消安全备份保存，则恢复操作也会取消。

完整恢复会替换当前浏览器中的全部活动数据。请确认选择的是正确备份文件。

九、按时间统计导出

点击“按时间导出”可以按活动创建日期选择范围。默认范围为最近一个自然月。

统计文件以人工阅读为目的：第一张工作表为“统计总览”，包含活动数量和各项金额汇总；后续每个活动各有一张工作表，列出活动概况和支出明细。

除了按时间导出，还可以在主页进入“活动管理”，勾选任意活动后使用“导出选中”。选中导出不要求活动时间连续，适合临时整理某几个活动；同样采用“总览 + 每活动一张工作表”的人工阅读结构。

统计导出与完整备份用途不同：统计导出适合阅读和归档；完整备份用于无损恢复系统。
