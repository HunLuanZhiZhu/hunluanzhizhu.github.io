# 活动经费记账助手

这是一个纯浏览器运行的单人活动经费记账工具，可直接部署到静态页面托管(GitHub Pages)。

## 使用方式

将本目录放到站点的 `projects/fund-manager/` 下即可。核心程序只有 `index.html`，无需构建、无需安装本地应用。

## 当前实现

- 浏览器本地数据库(IndexedDB)保存业务数据，不使用网络数据库。
- 主页一个活动一张卡片；活动编号始终取已有最大编号 + 1。
- 手工新建活动时只填写活动名称；预算金额和预支金额初始为 0。预支为 0 时，主页状态显示“未预支”。
- “新建活动”窗口可直接选择单个活动预算表创建活动。
- 顶部“导入工作簿”支持多活动预算批量导入、系统统计导出再导入，以及完整备份恢复。
- 子支出字段：物品、单价、总价、备注、已报销、报销日期。
- 勾选已报销时记录当天；取消时清空；再次勾选重新记录当天。
- 每个可编辑单元格显示独立的最后编辑日期。
- 已报销金额自动按已勾选支出总价求和；经费差额 = 预支金额 - 已报销金额。
- 首页不再把“预算金额”作为重点展示：活动卡片显示“预算剩余”；当已报销金额超过预算金额时，自动改为醒目的“超出预算”并显示超出金额。首页总览同时统计超预算活动数量。
- “经费已手动处理”可终止催办；取消后按原创建日期重新计算。
- 每次打开或刷新页面，按电脑当天日期重新计算催办状态；只有预支金额大于 0 的活动才参与催办判断。活动创建满一个自然月后，只要经费差额不为 0 且未勾选“经费已手动处理”，每次进入系统都会持续显示催办提醒。
- 普通模式主页隐藏金额；点击任一活动时需要输入密码，验证通过后仅本次活动详情显示全部真实金额，返回主页后重新打码。
- 全局秘密模式下主页和所有活动详情直接显示真实金额，进入活动不再重复验证；退出秘密模式时若正在活动详情，会返回普通主页。刷新页面后始终恢复普通模式。
- 密码仅以哈希值形式写入页面，用于普通模式与秘密模式的界面级隐私保护。
- 金额按分进行整数计算，界面最多两位小数，人工录入金额不允许负数。
- 活动级删除已集中到主页“活动管理”：进入管理后勾选活动，可批量删除或导出；批量删除需要二次确认。活动详情不再提供删除整个活动。删除单个子支出仍不需要二次确认。

## 内置使用说明

网页顶部提供“使用说明”入口，说明书直接写在单页 HTML 中，详细介绍新建活动、预算导入、活动与支出编辑、报销、催办、普通/秘密模式、完整备份恢复、按时间统计导出以及本地数据注意事项。说明书不展示实际密码。

## 预算表格式

普通预算表使用电子表格工作簿(XLSX)，表头：

| 活动 | 物品 | 单价 | 总价 |
|---|---|---:|---:|

同一文件允许多个活动；系统按“活动”分组。活动单元格为空时继承向上最近一个非空活动名称。单价允许留空。普通预算导入只接受这四个表头名称，不兼容旧表头。

“备注”属于活动内部的子支出字段，不属于普通预算导入格式。普通预算导入后备注默认为空，可进入活动详情手动填写。

“新建活动 → 选择单活动预算表”要求文件最终只识别出一个活动；包含多个活动时，应使用主页顶部“导入工作簿”。

## 导出

### 完整备份

一个工作簿：

- `总览`
- `活动_1`
- `活动_2`
- ……

用于无损恢复。恢复前会先要求保存当前状态的安全备份；如果取消该保存，恢复也会取消。

### 按时间导出

按活动创建日期筛选，默认时间范围为“今天往前一个自然月至今天”。

一个工作簿：

- `统计总览`
- 每个活动一个独立工作表

主要用于人工阅读。总览及各活动概况同时列出“超出预算”金额，便于发现已报销金额超过预算的活动。

## 文件保存行为

在支持文件系统访问接口(File System Access API)的浏览器和安全网页环境下，导出会打开系统“另存为”窗口；如果浏览器不支持，则自动退回浏览器普通下载。

电子表格解析与生成使用浏览器版电子表格库(SheetJS)。

## 界面设计说明

当前界面按“校园活动经费台账 / 档案桌”方向重新设计：

- 首页将活动总览和统计数据组合为一块台账抬头。
- 活动卡片使用账页横线、顺序编号水印和状态索引签条；状态包括未预支、已结清、待追缴、需追加经费和已手动处理。
- 活动详情采用核对单式布局，金额汇总与支出清单保持清晰的数据层级。
- 保留键盘焦点样式、窄屏适配和减少动画偏好。
- 视觉修改不改变原有本地存储、导入导出、密码模式与催办逻辑。

## 刷新时催办弹窗

- 每次首次打开或刷新页面后，系统会重新计算当前待催办活动。
- 如果存在待催办活动，会自动弹窗提示“当前共有 X 个活动处于催办状态，详见首页催办提醒区域”。
- 弹窗不展示金额和活动明细，关闭后可正常使用页面。
- 普通的数据编辑和界面重绘不会重复触发该弹窗。

## 首页筛选

首页支持组合筛选活动：

- 状态：全部活动 / 仅未结清。
- 时间：按活动创建日期设置开始日期和结束日期。
- 状态与时间可以同时使用。
- “未结清”包括未预支、待追缴和需追加经费；已结清和已手动处理不属于未结清。
- 点击“清除筛选”恢复显示全部活动。


## 活动批量管理

主页提供“活动管理”入口：

- 普通模式进入活动管理需要验证密码；秘密模式可直接进入。
- 进入后每张活动卡片出现选择框，可逐个选择。
- “全选当前结果”会选择当前搜索和筛选条件下显示的全部活动。
- “清空选择”取消全部选择。
- “导出选中”生成适合人工阅读的工作簿，第一张为“选中活动总览”，随后每个选中活动一张工作表。
- “删除选中”会二次确认后批量删除选中活动及其全部支出数据。
- 退出活动管理后，活动卡片恢复为点击进入详情。

## 页面内下载预算模板

主页提供“下载预算模板”按钮；“新建活动”窗口和内置使用说明中也提供模板下载入口。模板由网页即时生成。工作表左侧 A:D 是唯一正式填写区，第一行固定为“活动、物品、单价、总价”；E 列留空作为视觉分隔；F:I 是填写说明和文字示例。说明区与正式数据区完全分开，不参与导入，也不会把示例误导入系统。单价可以留空；同一活动后续行的活动名称可以留空并继承上方最近一个非空活动名称。填表人无需另外打开说明书即可按模板填写。

## 本地数据警示

内置说明书把“本地数据与备份（必读）”放在第一章并重点标示。业务数据只存在当前浏览器本地，更换电脑、清理网站数据、重置浏览器或浏览器故障都可能导致数据无法访问，因此应定期执行完整备份。
