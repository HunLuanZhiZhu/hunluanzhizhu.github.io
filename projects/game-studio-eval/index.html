评测设定

  1. 统一框架：每个模型拿到同一份 Game Studios（49 agents / 74 skills / 12 hooks）。

  4. 验收基线：能在浏览器完整游玩、核心循环跑通、零控制台错误。产物含网页版（Godot Web 导出）。
