AI 游戏生成评测

同一套 ZCode Game Studios 框架（源自 Claude Code Game Studios），仅给模型一个目标、全程零额外人工提示词，让它自主把游戏从概念做到可在浏览器游玩。本页横向对比各模型的「交卷」结果。

评测设定

  1. 统一框架：每个模型拿到同一份 ZCode Game Studios（49 agents / 74 skills / 12 hooks）。
  2. 唯一人工输入：一条 /goal 描述想要的游戏。
  3. 之后只触发 /auto-game-in-sleep，无人工追问、无人工改码，模型自主跑完设计→开发→构建→自测。
  4. 验收基线：能在浏览器完整游玩、核心循环跑通、零控制台错误。产物含网页版（Godot Web 导出）。
