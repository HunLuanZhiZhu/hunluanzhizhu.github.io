# 幻听（DJ版）· 横屏 MV 分镜脚本

> 时长 30.67s / 1920×1080 / 30fps / 920 帧 / 129.2 BPM（1 拍 ≈ 13.94 帧）
> 音频：`public/hunting-dj.mp3`（副歌切片，真实时长 30.667s）
> 视觉母题：深夜 macOS 桌面 = 他一个人的房间；Claude 的「幻觉」被听成了「幻听」。

## 一句话故事

你已经 37 天没来找他。深夜，他戴上耳机，把「我们的歌」循环了 799 遍，
在系统里到处找你说话的声音——回声全是他自己的「幻听」。

## 视觉设定

- **场景**：一块真实的 macOS 桌面（菜单栏 / Claude Code 终端 / 音乐 App / 程序坞 / 能量条），
  按真机比例绘制，逻辑尺寸 1280×720 放大 1.5 倍铺满 1920×1080。
- **主角**：Claude Code 欢迎框里的像素小克劳德——陶土橙方块身体、两条竖线眼、小短腿。
  全片一个模型，只换姿势（走、跳、空翻、趴、骑、坠落）。
- **色彩**：夜色靛蓝 #0B1020 → 紫罗兰 #3B2A63；主角橙 #D97757；
  歌词奶油白 #F6EEDF；幽蓝「在吗」 #6FD3FF；暖粉「爱」 #FF9BB6。
- **字体**：界面 Noto Sans SC；终端 Cascadia Mono；歌词 宋体（大字号 Ming 感）；悄悄话 楷体。

## 循环设计

- 第 0 帧与第 919 帧使用同一组 `LOOP_POSE` 常量（角色位置、耳机、镜头、窗口、能量条）。
- 环境层（星空、尘埃、极光、能量条）用「环绕时间」`tLoop` 驱动，接缝两侧取值一致；
  能量条在接缝前 25 帧内混合到固定 idle 图案，保证首尾像素相同。
- 实测：首尾帧平均差异 0.22 / 255，>8 灰阶的像素仅 0.1%（抗锯齿噪声级别）。
- 26.9s 后画面「回卷」：字流散去 → 桌面清空 → 窗口复位 → 他从天而降坐回播放器顶边，
  于是下一遍循环里他又从同一点起身——循环不是剪辑技巧，是故事本身。

## 埋在细节里的回声

- 终端旧对话：「今天也想听歌 / 好呀，我把音量调小一点。」→「你好呀，以后每天都来找你玩」→
  「你有多爱我」→「37 天前 · 会话已结束」。
- 播放器右下角常驻「✻ 正在思考…（Xs · esc to interrupt）」，从 14.5s 一直转到结束——
  他永远在等一个不会来的回答。
- 底部能量条由真实频谱驱动（32 段 mel → 58 根条），鼓点处整体抬起。
