一块深夜的 macOS 桌面，一个小克劳德，一个再也不会回复的输入框。整支 MV 由 Remotion（React）写成：像素小克劳德、终端、音乐 App、能量条全部程序化绘制，挂在 librosa 分析出的真实拍网上（66 个拍点、每帧 32 段频谱），只有一条连续镜头。这里没有视频文件——你看到的是浏览器正在逐帧现算的合成，拖动进度条可以直接跳到任意一帧。

本目录即完整 Remotion 工程（src/ · tools/ · script/storyboard.md），工程说明见 README.md。本地重建：npm install && npm run render（Node ≥ 20）；播放页 bundle 的构建入口在 player/entry.tsx。

实时渲染在你的设备上现场计算 1080p@30fps，低性能设备可能出现掉帧（本地 npm run render 导出 MP4 则永远满帧）。音轨取自参考片（许嵩《幻听》DJ 版副歌切片），仅作节奏对位与本地预览，版权归原作者所有；正式发布前请自行确认音乐版权授权。
