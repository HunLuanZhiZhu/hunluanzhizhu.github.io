AI 游戏生成评测 · 第二届

同一套 ZCode Game Studios 框架（源自 Claude Code Game Studios），仅给模型一个目标、全程零额外人工提示词，让它自主把游戏从概念做到可在浏览器游玩。本届为 2026-09 新开赛，选手持续增加中。

框架版本 · Framework

与第一届相比，本届所依赖的 ZCode Game Studios 框架已大幅重写：核心的 auto-game-in-sleep 无人值守流程改为证据门控的评审回环，视觉自检（vision）变为必备且阻塞、新增 CJK 字体支持、独立 playtest-reviewer agent 与 UX-first 的美术顺序，并收紧默认值与 hook 行为约定。

本届各选手使用的框架版本为 1.0.0 —— 该框架的首个稳定版（提交 987911a · 2026-09-11）。第一届使用的早期版本未记录对应 commit。

评测设定

  1. 统一框架：每个模型拿到同一份 ZCode Game Studios（49 agents / 74 skills / 12 hooks）。
  2. 唯一人工输入：一条 /goal 描述想要的游戏。
  3. 之后只触发 /auto-game-in-sleep，无人工追问、无人工改码，模型自主跑完设计→开发→构建→自测。
  4. 验收基线：能在浏览器完整游玩、核心循环跑通、零控制台错误。产物含网页版（Godot Web 导出）。
