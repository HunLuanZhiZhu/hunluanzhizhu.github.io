# 单篇论文生产总控

本 Skill 只负责**一次执行：选题 → 精读 → 生成 → 验收 → 发布 → 报告**。项目架构、目录规范、权限、自动索引和收藏机制见 `projects/arxiv-insights/AGENTS.md`，不在这里重复。仓库使用当前连接的 GitHub 账号对应的 `<github用户名>.github.io` 用户站点仓库，执行时以插件返回的实际仓库标识和默认分支为准，不固定特定用户。

## 1. 读取指令与检查候选

通过 GitHub 插件读取仓库根 `AGENTS.md`、`projects/arxiv-insights/AGENTS.md` 及以下两个子 Skill，并遵守其中全部强制要求：

- `projects/arxiv-insights/skills/arxiv-hot-papers/SKILL.md`
- `projects/arxiv-insights/skills/paper-html-explainer/SKILL.md`

按热点发现 Skill 搜索近期论文，核实 arXiv 版本、首次发表日期、全文可用性及带来源和观察时间的关注信号。优先有实质研究价值且可完整精读的论文；没有合格候选时本轮新增 0 篇，不为凑数伪造质量或热度。

对候选提取不带版本后缀的稳定 arXiv ID。**使用 GitHub 插件检查远程 `projects/arxiv-insights/papers/<稳定-id>/index.html` 是否存在**：已存在则视为已发布或待恢复，不能再次选中。**不读取、不修改 `data/papers.json`；它是自动生成的索引，不是去重依据。** 最终只选一篇。

## 2. 全文精读

阅读论文 HTML 或 PDF 的引言、方法、公式、实验、消融、限制及相关附录。每项重要结论、数字和公式记录原文出处；区分作者报告、外部证据和本站推断。若只能获取摘要或不足以核实主要结论，换候选；仍不合格则停止。

## 3. 生成单篇 HTML

遵循讲解子 Skill，生成 `projects/arxiv-insights/papers/<稳定-id>/index.html`：

- 中文译名与英文原题配对；提供「五分钟看懂」和「技术拆解」，为跨领域读者补足前置知识。
- 保留完整研究级技术内容。公式须真实渲染（MathML 或确实存在的本地数学资源），保留准确 LaTeX 原式，解释每个变量、索引、参数和非显然算子。
- 至少一张论文特有机制 SVG；适合时提供有明确教学意义的交互，区分示意模拟和论文实测。
- 使用简体中文界面，适配手机、键盘、深色模式及静态 GitHub Pages 子路径，不依赖外部不可信脚本。
- 在 `<head>` 内写入唯一的 `<script type="application/json" id="paper-meta">`，字段与约束按子项目 `AGENTS.md` 执行；特别确保 ID、原始发表日期、首次收录 UTC 时间、中文摘要和可核查热度真实准确。

## 4. 发布前验收

严格执行讲解子 Skill 的完整清单：核对论文版本、所有数字和公式出处、逐式符号释义、中文表达、SVG 和交互逻辑。必须使用实际浏览器检查桌面及 320、375、430、768 CSS 像素等移动视口的数学渲染、滚动、交互、链接和脚本错误。

**无法完成必要验收时，标记未验收或阻塞，不得宣称质量通过或直接发布。** 不能将静态代码检查冒充浏览器实测。

## 5. 通过 GitHub 插件发布

1. 仅在内容与验收合格且本轮具备写入授权时，使用 GitHub 插件重新查询远程目标 HTML 路径，确认不存在，防止并发覆盖。
2. 使用 GitHub 插件的创建文件接口**只新增这一篇 HTML**，不编辑已有文章、首页或共享 JSON。若创建失败或需要未获批准的权限，停止并报告；不得更换通道绕过拒绝。
3. 核对 GitHub 返回的提交 SHA 与远程 HTML 内容。索引由 GitHub Actions 自动从 HTML 生成；**单篇生产任务既不读取也不写入 `papers.json`**。
4. 如可通过 GitHub 插件查询 Actions 状态，确认索引生成是否成功；否则如实标记未核实。HTML 提交、索引生成与 Pages 线上部署是三个独立状态，不可混为一谈。

## 6. 报告与恢复

报告本轮新增 1 篇或 0 篇、稳定 arXiv ID/版本、中文及英文标题、首发日期、热度证据、全文阅读范围、公式与浏览器验收情况、HTML 路径、GitHub 提交 SHA，以及已核实的索引和部署状态。

如果目标 HTML 已存在但首页未收录，报告为**自动索引或部署待恢复**，不要重新生成同一论文，也不要直接编辑 JSON。权限拒绝、质量不足或无法验收时明确说明阻塞原因。

本 Skill 不创建、不修改、不启用定时任务；每次执行最多发布一篇。
