# arXiv 单轮论文生产总控

## 一、边界与输入

每轮最多一篇，不因产量目标降低质量。通过 GitHub 插件只读获取仓库根目录 `AGENTS.md`、`projects/arxiv-insights/README.md`、本文件，以及 `projects/arxiv-insights/skills/arxiv-hot-papers/SKILL.md` 和 `projects/arxiv-insights/skills/paper-html-explainer/SKILL.md`。按两份子 Skill 的全部学术、中文、数学、交互和浏览器标准执行。

自动任务禁止读取或编辑 `data/papers.json`，禁止写入任何仓库文件，禁止 GitHub 写入、提交、推送、发布、索引更新及部署操作。不得运行发布脚本或监控服务，不得配置、暂停或调整定时任务。

## 二、发现与去重

检索最近七天 arXiv 机器学习及相关领域论文，核实原始发表日期、作者、版本、全文、Hugging Face 等社区关注信号及观察时间。必要时选择尚未解读的高价值历史论文。去掉版本后缀得到稳定 ID，通过 GitHub 插件只读核查远程 `projects/arxiv-insights/papers/<稳定-id>/index.html` 路径，并核查当前可访问的既有任务附件，避免重复。无法穷尽历史附件时明确说明去重范围。按研究价值、证据质量与教学价值排序，只选一篇；无合格候选则报告零篇。

## 三、精读与生成

获取论文正式 HTML/PDF 全文，核查引言、相关工作、方法、关键公式、实验、消融、局限和必要附录。所有量化结论必须注明原文出处、指标、数据集和基线；区分作者声称、独立验证与本站推断。只得到摘要不得冒充精读。

生成完整中文静态交互 HTML，包含中英文标题、「五分钟看懂」与「技术拆解」、必要前置知识、论文专属 SVG、合理交互和局限分析。全部公式须真正渲染，保留 LaTeX 源并逐式解释所有变量、上下标和非显然符号；不得依赖未知远程脚本。

HTML 草稿保留唯一 `paper-meta` JSON 和可核实的元数据。尚未实际收录时不得虚构 `added_at`；正式首次收录时间由后续人工发布阶段确定、补齐并重新验证。

## 四、严格验收

逐项执行讲解子 Skill 的全部验收清单，包括证据、数学源与渲染、中文术语、教学结构、交互、可访问性和版权。必须使用真实浏览器检查桌面、320、375、430、768 CSS 像素宽度、适用横屏、键盘、触控、深色模式、页面缩放、链接和脚本错误。整页不得横向溢出，长公式可在局部容器滚动。没有真实浏览器或数学验证，不能宣称验收合格。

## 五、ChatGPT 附件暂存

仅在验收合格后将完整 HTML 作为当次 ChatGPT 任务消息的可下载附件交付。不得把草稿写入 GitHub 或本地仓库；不得调用任何发布程序。附件不保证永久可访问；生成或附加失败必须报告失败，不得宣称已经保存。

## 六、独立人工发布

只有用户在普通对话中明确批准，才可在独立流程中收集仍可访问的未发布附件、审核、核对远程稳定 ID 路径，并通过 GitHub 插件集中提交。索引和 Pages 状态由该阶段独立核实，不属于自动生产。

## 七、结果报告

报告本轮时间、零篇或一篇、论文稳定 ID 与版本、中文及英文标题、真实发表日期、热度来源和观察时间、全文阅读范围、公式与浏览器验收情况、可验证的附件链接。不得把未发生的远程提交或部署称为成功。
