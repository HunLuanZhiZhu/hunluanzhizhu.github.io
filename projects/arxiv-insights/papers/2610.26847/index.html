让智能体在运行中切换权重

WeAct: Dynamic Weight Switching as Agent Actions
把能力选择变成模型自己的内部动作

同一个研究智能体，为什么不能在“制定计划、查证事实、撰写报告”时使用不同的专长参数？WeAct 把加载与卸载低秩适配器变成可调用的工具，而不是把所有技能永久揉进同一套权重。

01 / 五分钟看懂

一个研究任务，不该只有一副固定“大脑”

先看真实问题：智能体接到“调研一种新药是否有效”时，至少要决定检索方向、搜集证据、比较结论并撰写报告。每个阶段的能力分布不同。

01
共享训练会互相覆盖

先学搜索，再学写作，后一次参数更新可能侵蚀前一次获得的技能。

02
静态融合不等于切换

把多个低秩更新合并成固定权重，可能削弱各自对目标阶段的适配效果。

03
让智能体自己换权重

用内部工具调用激活对应模块，仍沿用同一条任务历史与外部工具接口。

核心区别：传统工具调用改变外部世界（例如搜索网页）；WeAct 的“内部动作”改变下一次生成使用的模型参数。它不是同时把三个适配器混合起来，也不是为每个阶段启动独立智能体。

02 / 前置知识

先理解三个必要概念

低秩适配（Low-Rank Adaptation，LoRA）

不直接更新大模型的完整权重矩阵，而是训练两个较小矩阵，其乘积作为额外权重。输入仍是原始隐藏状态，输出是经过“基础权重 + 低秩增量”变换的隐藏状态。本文用它为规划、检索、写作分别存放可替换的专长。

灾难性遗忘（Catastrophic Forgetting）

学习新能力时，旧任务表现下降。例如训练同一适配器更擅长写报告，可能让它之前学到的证据检索行为变差。本文通过分开更新参数，降低跨模块的直接覆盖风险，但不保证系统行为永远不退化。

执行框架（Agent Harness）与工具调用（Tool Calling）

执行框架负责维护历史、调用外部工具、处理工具返回以及限制权限。WeAct 在此框架中新增“加载适配器”和“卸载适配器”两种内部工具；一次切换后，后续生成由新权重负责，而不是仅改变提示词。

键值缓存（Key–Value Cache）

注意力机制为了避免重复计算，通常缓存历史词元的键和值。由于切换适配器会改变计算权重，论文的实现需要在新权重下重建保留历史的缓存；因此权重切换并非零开销。见附录 B.3。

03 / 交互式机制

亲自操作一次“内部动作”

选择控制策略并逐步执行。绿色节点表示当前生效的权重；每一步都保留共同历史。这是依据论文第 2.3 节构造的确定性教学流程，不是运行 Qwen3-32B，也不是论文的实测轨迹。

基础权重规划检索写作

状态变化规则：空闲 → 加载某适配器 → 该适配器卸载 → 空闲 → 加载下一适配器。重复加载和不合法卸载不会改变活动状态。

两种控制策略并不等价

规定顺序（WeAct-hard）默认强制按规划、检索、写作顺序使用适配器，减少漏调用；灵活选择（WeAct-soft）由当前上下文决定调用哪种能力，允许重访，但需要覆盖率、重复和终止约束。论文表 1 的平均准确率分别为 45.47% 与 43.21%，不能仅凭灵活性判断效果更好。

04 / 技术拆解 · 公式

把权重切换写成可核对的数学过程

以下公式保留论文原始符号；数学使用浏览器原生数学标记语言排版，每组附原始 LaTeX 源及完整中文符号解释。

公式 1：一个专长如何改动权重？

论文第 2.1 节式 (1)。对每个需要适配的线性层，保持基础权重不变，只学习两个低秩因子。

Wk,ℓ=W0,ℓ+αkrkBk,ℓAk,ℓ
论文式 (1) · 低秩权重增量
逐符号：Wk,ℓ 是激活能力 k 后第 ℓ 个线性层的有效权重；W0,ℓ 是冻结基座的同层权重；k 是能力编号（例如规划）；ℓ 是层/线性映射索引；αk 是缩放系数；rk 是低秩维度（正整数）；Bk,ℓ 与 Ak,ℓ 是训练的矩阵因子，形状分别为“输出维度 × r”和“r × 输入维度”；相乘得到与原权重同形状的增量。
查看原始 LaTeX 与形状
W_{k,\ell}=W_{0,\ell}+\frac{\alpha_k}{r_k}B_{k,\ell}A_{k,\ell}
A_{k,\ell}\in\mathbb{R}^{r_k\times d_{\mathrm{in},\ell}},\quad B_{k,\ell}\in\mathbb{R}^{d_{\mathrm{out},\ell}\times r_k}

公式 2：哪套参数生成下一个动作？

论文第 2.1 节式 (2)。选择活动模块的索引后，下一步仍根据共同历史进行条件生成。

at∼πzt(·|ht)=πθ0+Δθzt(·|ht)
论文式 (2) · 当前权重对应的生成策略
逐符号：at 是第 t 步生成的动作/文本或工具调用；t 是交互步索引；“∼”表示从概率分布采样；π 是生成策略/条件概率分布；下标 zt 表示当前活动适配器编号，可为空；“·”是尚待采样的输出；竖线“|”表示在历史条件下；ht 是截至此步的任务与工具历史；θ0 是冻结基础模型参数；Δθzₜ 是活动适配器提供的参数增量，空状态的增量为零；“=”表示两种记法定义同一策略。
查看原始 LaTeX
a_t\sim\pi_{z_t}(\cdot\mid h_t)=\pi_{\theta_0+\Delta\theta_{z_t}}(\cdot\mid h_t)

公式 3：为什么共享参数会互相干扰？

论文第 2.2 节式 (3)，在局部平滑的假设下作一阶泰勒展开。

Lj(ω−ηgk)−Lj(ω)=−ηgj⊤gk+O(η2)
论文式 (3) · 更新另一能力后当前损失的变化
逐符号：ℒj 是能力 j 的共享参数训练损失；j 与 k 是两个能力索引；ω 是被共同更新的参数向量；η 是正的学习率；gk、gj 分别是能力损失对 ω 的梯度；上标“⊤”是转置，因此 gj⊤gk 为内积；O(η²) 是二阶及更高阶的余项。若梯度内积为负，一阶近似预示能力 j 的损失上升；但正内积也不保证长程训练不会遗忘。
查看原始 LaTeX
\mathcal{L}_j^{\mathrm{shared}}(\omega-\eta g_k)-\mathcal{L}_j^{\mathrm{shared}}(\omega)=-\eta g_j^\top g_k+O(\eta^2)

公式 4：只监督当前能力的输出

论文第 2.2 节式 (5)。训练样本保留先前对话和工具观察作为上下文，但只对当前阶段的助手输出与交接调用计损失。

Lk(φk)=−Es∼Dk∑n=1Nmk,nlogπk(xn|x<n)
论文式 (5) · 分阶段带掩码的负对数似然
逐符号：ℒk 是能力 k 的训练损失；φk 是该能力全部可训练低秩矩阵；𝔼 表示对样本取期望；s 是从该能力数据集 𝒟k 采样的一条完整词元序列；n 是词元位置索引，N 是序列总长度；mk,n 为二值掩码：属于当前阶段助手目标时为 1，否则为 0；πk 是激活能力 k 时的模型；xn 是第 n 个目标词元；x<n 是前面全部词元；log 是自然对数；“∑”表示累加所有位置，前置负号把高概率目标对应为较低损失。
查看原始 LaTeX
\mathcal{L}_k(\phi_k)=-\mathbb{E}_{s\sim\mathcal{D}_k}\sum_{n=1}^{N}m_{k,n}\log\pi_k(x_n\mid x_{<n})
最容易误解的一点：掩码为零的历史词元仍参与因果注意力，作为条件信息；只是它们不贡献当前适配器的训练目标。每个阶段还要学习何时发出“卸载”调用，把控制权交回执行框架。

公式 6：怎样量化遗忘？

Fk=Akown−AkfinalAkown−Ak0

逐符号：Fk 是能力 k 的遗忘比例；k 是能力编号；A 表示验证集上的内容词元准确率；上标 0 表示训练前，上标 own 表示该能力自己的训练阶段结束时，上标 final 表示所有能力阶段结束时。分母是该能力曾获得的提升，分子是之后损失的提升；分母为零时比值无定义。附录表 7 中共享秩 96 的写作能力约丢失 49.2% 的已获得收益，而独立适配器的对应损失为 0（参数不再更新的特定实验设置）。

效率与代价：不能只看加速数字

作者按附录 B.1 的浮点运算估算，WeAct 训练消耗 142.8 EFLOPs，比该实验的全参数微调少 7.3%，但相比单一 LoRA 的总计算量约为 1.96 倍。同一组 50 次 WebWalkerQA 运行中，固定顺序与灵活选择相对于全参数微调的平均“得到答案所需时间”分别减少 20.3% 和 33.4%（附录 B.3）。

切换也要付费：新权重需要重建历史键值缓存；适配器控制与缓存处理合计占灵活选择/固定顺序版本时间的 8.2% / 2.8%。这些结果受部署方式、任务长度、重试策略与工具耗时影响，不能外推为所有硬件上的加速比。

训练数据与复现实务

主训练集包含 6,962 条来源轨迹（MiroVerse 5,887 条；OpenSeeker 补充 1,075 条），按能力切分后分别形成规划 6,962、检索 7,437、写作 6,962 个阶段样本（附录 A）。主适配器秩为 32 / 64 / 32；检索秩更高，是因为作者观察到秩 32 时容易反复推理或不能可靠退出（附录 F）。

作者做过训练/评测任务文本重合筛查：在 MuSiQue 的 2,417 道问题中有 63 道与训练子任务出现答案相关的重合；剔除后方法排序未变，但筛查无法排除低于词汇阈值的语义改写重合（附录 A）。

06 / 研究判断与局限

“参数不被覆盖”不等于“行为永不退化”

  • 模块数量：论文尚未证明当能力库增长到几十或几百个适配器时，模型仍能可靠地挑选、退出并重访正确模块（第 7 节局限）。
  • 边界含糊：规划、检索和写作在真实任务中会交织；划分不准时，独立训练反而可能造成路由错误。附录 A.2 显示细分标签对标注规则较敏感。
  • 旧模块的内部遗忘：写作模块被继续训练时，原有写作子能力仍可能退化。附录表 12 显示刷新后历史写作验证集的负对数似然从 0.46 上升到 0.50，不能只看新任务分数上升。
  • 系统代价：适配器需驻留设备并在切换时重建缓存；固定顺序对阶段结构有假设，灵活选择对工具调用与终止机制有要求。
  • 证据边界：当前结果主要来自 Qwen3-32B 与深度研究任务，尚非跨模型规模、跨部署架构的独立验证。作者报告的指标不能证明“普遍解决灾难性遗忘”。
本站分析：WeAct 最有价值的思想不是“多训练几个 LoRA”，而是将可更新的能力模块和可审计的运行时权重选择结合起来。它把传统静态参数组合问题转成一个带状态与权限的序贯决策问题；这也意味着路由可靠性和缓存成本成为新的研究瓶颈。
