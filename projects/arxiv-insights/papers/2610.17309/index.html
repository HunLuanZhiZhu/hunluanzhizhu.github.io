强化学习 × 概率校准 × 按需推理

StartLux-Decision：让决策模型学会何时思考、如何校准信心

StartLux-Decision: AutoThink Decision Models with Reinforcement Learning for Calibrated Deliberative Decisions

不是每个问题都需要长篇推理。先给出概率，遇到不确定情况再思考；训练时奖励“推理让概率变得更可靠”，而不只奖励猜对答案。

五分钟看懂：给“思考”设置一道门

01 · 问题

单次判断太快

很多决策模型只读一遍输入就给出“批准 / 拒绝 / 转人工”的概率。面对政策例外、计算和多条件判断时，单次读出容易漏掉关键条件。

02 · 传统代价

每题都推理又太慢

生成一长串推理词元（Token）需要逐步计算；长推理还可能陷入重复、无法按时结束，且高置信度并不保证概率已经校准。

03 · 本文变化

先读概率，必要时再推理

快速决策版采用单次前向读出；自动思考版在最高选项概率低于 0.9 时才生成推理，再把推理前后概率按 25% / 75% 融合。

把三个目标分开：准确率衡量选项是否答对；概率质量衡量“报 80% 的事情是否真的约有 80% 正确”；推理成本衡量额外生成多少词元。论文同时优化这三者，但它们不等价。

一个真实论文例子：8 条数据能否导出？

政策有“法律保全需升级审核”的规则，但“少于 100 条记录”构成例外。模型必须检查规则优先级，而不是仅凭“有保全”就转人工。

首次读出把“转人工”估为 0.567、“批准”估为 0.408；最大概率不足 0.9，触发推理。

① 类型化决策与概率读出（Typed Decision / Probability Readout）

是什么：给定输入状态、一个问题与候选选项，输出每个选项的概率。输入可以是文本、结构化字段或图片；输出不是长篇回答，而是一组和为 1 的概率。

为什么：下游系统需要知道是否可以自动执行、请求强模型或转人工。本文位置：第 2.1 节，使用选项字母对应的输出对数值（Logit）经过温度缩放和归一化得到概率。

② 正确评分规则（Proper Scoring Rule）

是什么：一种给概率预测打分的方法；在期望意义下，诚实报告真实概率才最优。输入是预测概率与真实标签，输出是分数。它区别于只看最大概率选项是否猜对的 0/1 奖励。

本文位置：第 3.1 节，以推理前后评分的差值构成奖励。平方误差式的布里尔分数（Brier Score）与对数分数（Log Score）是常见例子；发布模型使用决策加权分数。

③ 强化学习、策略与优势（Reinforcement Learning / Policy / Advantage）

是什么：策略是模型在给定上下文时生成下一词元的概率分布。采样若干推理轨迹，每条轨迹得到奖励；优势值比较该轨迹与同组平均奖励。输入是问题、采样轨迹和奖励；输出是参数更新方向。

本文位置：第 3.2 节，组相对策略梯度与裁剪比率控制更新幅度，另用参考策略的散度约束偏离。

④ 概率校准与选择偏差（Calibration / Selection Bias）

是什么：报出 0.8 置信度的预测，在同类样本上应约 80% 正确。输入是模型概率和真实结果，输出是置信度映射或校准误差。

本文位置：第 5.4–5.5 节。挑最高分候选会改变被返回样本的分布，原先在单样本上校准的概率可能在实际路由策略下失准；因此校准必须考虑选择策略。

技术拆解：从概率接口到策略优化

三阶段训练为何分开？

第一阶段，全参数监督微调（Supervised Fine-Tuning，SFT）：将分类、问答、工具调用等数据改写为类型化决策；0.8B–9B 约 270 万条，27B 约 80 万条。用目标概率分布与预测分布的软交叉熵训练概率读出。

第二阶段，适配器（Adapter）训练：约 170 万条更广泛决策数据；快速版在全注意力层采用双向注意力，自动思考版保留因果注意力以便继续生成推理。4B/9B 的 32 层中有 8 层为可改成双向的全注意力层，线性注意力层仍保持因果。

第三阶段，推理监督＋强化学习：自动思考版先以约 4,000–21,000 条推理监督样例学会生成与结束，再用校准式审慎决策强化学习（Reinforcement Learning for Calibrated Deliberative Decisions，RLCD²）训练“有用且不过长”的推理。冻结起始模型负责概率打分，更新的是生成推理的策略。

① 概率读出：一组候选对数值如何变成概率？

原论文公式（1） · 第 2.1 节

温度缩放的选项归一化

公式把原始选项分数变成可以用于路由的概率分布。

pk=exp⁡(zk/T)∑j=1Kexp⁡(zj/T),k=1,…,K

长公式可在此区域横向滚动，完整数学源可在下方展开。

逐符号解释：

pk：第 k 个选项的输出概率；zk：对应选项字母在最后提示位置的对数值；T：正温度参数，使用留出集拟合；K：候选选项总数；k、j：选项索引，从 1 到 K；zj：分母中第 j 个选项的对数值；exp：自然指数函数；∑：遍历全部选项求和；分数线：分子对数值指数除以全部指数之和。

直觉与例子：若两个选项对数值相等，二者概率各为 0.5；温度升高会让分布更平缓，但不会改变选项排序。

查看 LaTeX 原式（供复核，不替代数学排版）
p_k=\frac{\exp(z_k/T)}{\sum_{j=1}^{K}\exp(z_j/T)},\quad k=1,\ldots,K
原论文公式（2） · 第 2.2 节

门槛与推理前后概率融合

高置信度直接返回，低置信度才为推理付出生成成本。

pdefault={p0若 maxkp0,k≥g(1−α)p0+αp1若 maxkp0,k<g,g=0.9,α=0.75

长公式可在此区域横向滚动，完整数学源可在下方展开。

逐符号解释：

pdefault：最终输出的整组候选概率；p0：单次读出的初始概率向量；p1：生成推理后的概率向量；p0,k：初始向量中第 k 个选项的概率；k：候选索引；max：取各选项概率的最大值；g：触发门槛，默认 0.9；α：推理后分布的融合权重，默认 0.75；1−α：初始分布的权重；≥、<：两条互斥分支的比较条件；0、1 下标分别表示推理前与推理后。

直觉与例子：若最高初始概率为 0.95，直接输出；若为 0.567，则推理后按 0.25×初始分布＋0.75×推理后分布融合。上方滑杆实时计算这个式子。

p_{\mathrm{default}}=\begin{cases}p_0,&\max_k p_{0,k}\ge g,\\(1-\alpha)p_0+\alpha p_1,&\max_k p_{0,k}<g,\end{cases}\quad g=0.9,\ \alpha=0.75

② 正确评分规则：不只奖励猜对

平方误差式的布里尔分数与对数分数是第 3.1 节列举的参照；发布模型使用下述对高置信区间更敏感的决策加权规则。评分越大越好。论文的加权函数为均匀密度与贝塔分布（Beta Distribution，参数为 8 和 2）密度的等权混合。

原论文公式（3） · 第 3.1 节

决策加权分数与两个积分

对每个候选选项的概率进行评分，随后将各选项分数相加得到整组决策的评分。

s(q,z)=zW(q)−C(q)W(q)=∫0qw(c)dcC(q)=∫0qcw(c)dc

长公式可在此区域横向滚动，完整数学源可在下方展开。

逐符号解释：

s(q,z)：某个选项的评分；q：该选项报告的概率，范围 0 到 1；z：该选项是否真实正确的二元标签，正确为 1、否则 0；W(q)：权重密度 w 从 0 到 q 的积分；C(q)：概率位置 c 乘以权重密度后的积分；w(c)：对置信度 c 的非负权重密度；c：积分中的概率位置（积分哑变量）；∫、dc：在 0 到 q 区间对 c 积分；0、1：概率区间端点和二元标签取值。

论文取 w(c) 为均匀密度与 Beta(8,2) 密度各占一半。Beta 的两个形状参数分别为 8 与 2，使高置信区间得到更高权重。对于多选项分布，对每个选项应用 s 再求和，称为 SD(p,t)：p 是所有选项的预测概率向量，t 是对应的真实目标分布。

直觉与例子：若一个选项真实正确（z=1），把 q 从 0.4 提高到 0.9 往往改善评分；若该选项实际错误（z=0），提高 q 则会受罚。上方“软预算”演示使用此式的精确积分。

查看 LaTeX 原式（供复核，不替代数学排版）
s(q,z)=zW(q)-C(q),\quad W(q)=\int_0^q w(c)\,dc,\quad C(q)=\int_0^q c\,w(c)\,dc
原论文公式（4） · 第 3.1 节

为什么诚实概率最优？

对期望评分求导，说明评分规则为何鼓励校准概率。

∂∂qE[s(q,z)]=w(q)(π−q)

长公式可在此区域横向滚动，完整数学源可在下方展开。

逐符号解释：

∂/∂q：对报告概率 q 求偏导；𝔼：对真实二元结果 z 的伯努利分布取期望；s(q,z)：公式（3）的选项评分；q：报告概率；z：正确性标签，取 0 或 1；w(q)：在 q 位置的权重密度；π：该选项真正正确的概率，范围 0 到 1；π−q：真实概率与报告概率的差。

直觉与例子：如果真实正确率 π 为 0.7，而模型报 q=0.5，导数为正，增大 q 能提高期望分数；若报 q=0.9，导数为负，应降低 q。若 w 在相关区间严格为正，最优点唯一地落在 q=π。

查看 LaTeX 原式（供复核，不替代数学排版）
\frac{\partial}{\partial q}\mathbb{E}[s(q,z)]=w(q)(\pi-q)

③ 推理奖励：改善概率分数，惩罚超长轨迹

原论文公式（5） · 第 3.1 节

冻结评分器给每条推理轨迹打分

奖励是“推理后评分减推理前评分”，再减去超预算词元的软惩罚。

r(x,τ)=S(p1(x,τ),t)−S(p0(x),t)−λmax(0,|τ|−B)

长公式可在此区域横向滚动，完整数学源可在下方展开。

逐符号解释：

r(x,τ)：给定输入 x 与推理轨迹 τ 的总奖励；x：问题、状态及候选选项；τ：模型生成的推理词元序列；p0(x)：冻结起始模型的推理前概率分布；p1(x,τ)：同一冻结模型读完轨迹后的概率分布；t：目标正确分布；S：对整组候选概率打分的正确评分规则，发布模型使用公式（3）的决策加权规则；λ：每个超预算词元的惩罚系数，原文为 0.0001；|τ|：推理词元数；B：软预算，发布配置为 3,072；max(0,·)：负超额截为 0，即未超预算不罚；0：惩罚下界。

直觉与例子：当轨迹长度为 3,500、预算为 3,072 时，超额为 428 词元，惩罚为 0.0428；即使超预算也允许继续生成（直至独立的 4,096 生成上限）。

r(x,\tau)=S\big(p_1(x,\tau),t\big)-S\big(p_0(x),t\big)-\lambda\max\big(0,|\tau|-B\big)

④ 更新推理策略：裁剪优势与参考策略约束

原论文公式（6） · 第 3.2 节

组相对策略梯度的裁剪目标

最小化负的裁剪策略收益，同时惩罚过度偏离参考策略。

L=−1N∑i∈T∑s=1|τi|min(ρi,sAi,clip(ρi,s,1−ε,1+ε)Ai)+βKL^(πθ‖πref)

长公式可在此区域横向滚动，完整数学源可在下方展开。

逐符号解释：

ℒ：最小化的训练目标；N：当前批次生成的总词元数；𝒯：批次中采样推理轨迹的索引集合；i：轨迹索引；s：该轨迹内部的词元位置，从 1 到轨迹长度；τi：第 i 条推理轨迹；|τi|：其词元数量；ρi,s：当前策略与采样策略在该词元上的概率比；Ai：第 i 条轨迹的组内优势，等于该轨迹奖励减组均值后裁剪到 −5 至 5；min：取两个策略收益中的较小者；clip：把概率比限制在指定区间；ε：概率比裁剪幅度，非负超参数；1±ε：裁剪上下界；β：参考策略散度的正则权重；KL̂：词元平均的库尔贝克—莱布勒散度（Kullback–Leibler Divergence）估计；πθ：参数 θ 控制的当前生成策略；πref：固定参考策略；θ：待优化模型参数；‖：散度表达式中两个分布的分隔符，并非向量范数；∑：对批次轨迹及各轨迹词元求和。

直觉与例子：若一组推理轨迹奖励分别为 0.2 和 0.4，则组均值为 0.3，优势分别为 −0.1 与 +0.1；高于组均值的轨迹被鼓励，但概率比的裁剪和散度项限制一次更新的幅度。这个数值是教学例子，不是论文训练记录。

\mathcal{L}=-\frac{1}{N}\sum_{i\in\mathcal{T}}\sum_{s=1}^{|\tau_i|}\min\Big(\rho_{i,s}A_i,\;\mathrm{clip}(\rho_{i,s},1-\epsilon,1+\epsilon)A_i\Big)+\beta\widehat{\mathrm{KL}}(\pi_\theta\|\pi_{\mathrm{ref}})
重要的因果区分：冻结评分器只给轨迹打分，不意味着强化学习不更新模型；实际被优化的是生成推理的策略参数。对同组非空轨迹，初始概率分数是共同常量，在奖励中心化时会相消；空轨迹被赋零奖励。论文没有按组内标准差归一化优势。

作者结论、证据边界与本站判断

作者报告支持什么

单次概率读出与按需推理可共用概率接口；正确评分规则配合软长度惩罚能显著减少部分模型的推理拖尾。270 亿模型在 DecisionPivot 上达到 86.9% 成对准确率；策略感知校准减小选择／路由后的信心偏差。

尚不能推断什么

不能由公开 DI 分数推断全领域最优；不能由词元数推断真实系统延迟或总能耗；不能从程序合成对照题直接推断真实高风险业务表现；不同量化后端也不必然保持完全相同的概率数值。作者在附录 A.4 注明推理代码采用 Apache-2.0 许可证，模型权重采用仅限非商业用途的 CC BY-NC 4.0 许可证。

本站研究判断（非作者实验证明）

论文最值得借鉴的不是固定的 0.9 门槛，而是把“是否继续思考”视为一个可检验的决策，并用概率质量变化而非单一答对率来训练。若部署环境存在候选筛选、级联或人工复核，概率校准应绑定到完整工作流，而非只测裸模型。

下一步最有价值的复现是：在未见过的真实业务规则、不同错误成本和延迟约束下，分别测量逐题准确率、成对准确率、校准误差、终止率、端到端耗时与置信区间，并检查阈值迁移性。270 亿模型的强化学习增益很小，提示训练收益与起始推理行为有关。
