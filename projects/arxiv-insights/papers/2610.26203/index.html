一个手机智能体同时看到画面、听到声音、追踪视频，还记着自己刚刚点过什么。它的困难并不只是“看得不够多”，而是每一步需要相信的证据都在变化。FocusGUI 的方法：保留全部输入，只改变冻结解码器在动作前如何优先读取它们。

输入：用户目标、屏幕、音频、视频、历史、设备状态。中间：七个证据通道的优先级与紧凑聚焦向量。输出：原始解码器生成的结构化动作及坐标、文本参数。

别把“更准”误解成什么

论文的主要指标是已记录交互步骤的动作匹配和轨迹正确步骤占比；并非真实开放互联网环境中任意任务的端到端成功率。作者没有报告独立第三方复现。

02 / 预备知识

跨领域前置知识地图

逐卡说明是什么、为什么需要、输入输出与对应步骤；熟悉的读者可跳过。

① 图形界面智能体与闭环控制

图形界面（Graphical User Interface，GUI）智能体把用户目标与观测转换为可执行动作，如点击、输入、滑动或等待。动作执行后会改变屏幕和历史，下一步又要观察。这是闭环而非一次性分类；输入为多模态观测，输出为动作，关联公式 1、2。

② 多模态证据与通道分解

全模态（Omni-Modal）指文本、图像、声音、视频等同时进入模型。通道分解（Channel Decomposition）把不同来源映射到共同的向量空间，使它们可以比较；输入是每种来源的特征，输出是 128 维向量，关联公式 3。

③ 软最大归一化与温度

软最大（Softmax）把任意实数分数转成非负且和为 1 的权重。温度控制权重分布的尖锐程度；输入为七个通道得分，输出为七个权重，关联公式 4、5 与下面的滑杆。

④ 嵌入、残差与冻结参数

嵌入（Embedding）是解码器处理的连续向量；残差（Residual）是叠加的小改动。冻结参数（Frozen Parameters）指训练时不更新底座权重，只更新旁路适配器；输入为 64 维潜向量，输出为动作前四个嵌入位置的加性改动，关联公式 2、7。

⑤ 词元监督与负对数似然

词元（Token）是生成动作文本的基本单位。教师强制（Teacher Forcing）在训练时给模型正确的前缀，优化正确下一词元的对数概率；输入为标注动作序列，输出为训练损失，关联公式 8。不需要告诉模型“本步该关注音频”。

⑥ 类型匹配、精确匹配、目标进度

动作类型匹配（Type Match，TM）只检查“点击还是等待”等动作类别；精确匹配（Exact Match，EM）还要求坐标落在目标框、输入文本与参考一致；目标进度（Goal Progress，GP）为每条轨迹中正确执行步骤的比例再跨轨迹平均。三者越高越好，关注的错误层次不同。

公式 01 · 原文 §2 的问题定义（非编号公式）正文第 3 页
Ot={g,It,Vt,At,Ht,St}

计算目的：规定智能体在第 t 步到底能看到什么，强调不能删掉某种输入。

完整符号词典：O_t：第 t 步完整观测集合；t：步骤索引；g：用户目标；I_t：当前执行屏幕；V_t：时序视频观测；A_t：音频观测；H_t：既往动作及交互历史；S_t：设备状态；花括号表示将这些部分组成集合。

直觉与核对：例如“听到发动机声音再暂停视频”，仅有 I_t 不够；还需 A_t 与 V_t。

在千问 2.5 全模态底座上，完整模型为 71.65 / 40.16 / 17.49（类型／精确／进度）。移除“通道分解”后为 66.26 / 35.00 / 12.20；移除“动态赋权”后为 67.38 / 37.78 / 11.56；移除“加性残差对齐”后为 70.45 / 34.86 / 12.11。来源：表 2。

参数量匹配的固定拼接对照与动态赋权对照，精确匹配为 33.46% 与 37.01%，进度为 10.14% 与 13.58%；这项单独实验使用 508 个测试步骤，见附录 C.3 表 5。它们的数值不应与表 2 的默认训练配置直接拼接成同一行。

容量与交互深度：两条反证

将聚焦维度从 64 降到 32，精确匹配从 40.16% 降到 33.27%，进度从 17.49% 降到 10.95%；不是压缩越狠越好（表 3）。

冻结千问底座的动作类型匹配从第一步 64.79% 降至第四步及以后 32.79%；FocusGUI 在相同跨度保留初始水平的 86.8%。这是按步数分组的观测相关性证据，见图 3，不能单独证明全部收益都由“序列分心”引起。

解释指标差异：同一个动作可以“类别正确但参数错误”。例如模型决定“点击”得到了类型匹配分，却点在目标按钮外就不能得到精确匹配分。论文观察到多种屏幕裁剪方法对类型匹配接近中性，但使精确匹配与轨迹进度下降；保留原始观测有实际意义。
06 / 边界与判断

作者结论、证据限制与本站判断

作者报告的结论

在 OmniGUI 的四种全模态底座和五类任务中，少量可训练残差适配器能够提高下一步动作类别与参数匹配，并缓解交互加深时的性能衰退。该结论受表 1–3 与图 3–4 支持。

数据与外推限制

只有一个主要基准，且测试集为 142 条轨迹；它不等于开放网络中可持续运行的真实代理。附录 B 也承认目前仅使用当前步骤观测估计重要性，尚未预测下一步将出现什么证据。

训练与工程成本

虽然仅训练约 115 万至 145 万参数，但仍需冻结底座提取多模态特征、保存中间证据，并经过训练；作者使用两张 L20 图形处理器。论文没有给出可泛化到所有部署场景的端到端时延节省比例，不能声称“免费增强”。

本站分析（非作者证明）

最有价值的设计是把“保留证据”和“调度证据”分开：前者避免丢失坐标与文本，后者为当前决策提供轻量提示。需要进一步研究主动感知、未来模态预测和跨任务泛化，以及模型对模态优先级的因果可解释性。

代码仓库已公开，但未在本轮重新训练或复现实验；论文中 45.3%、90.1% 等诊断比例也不是我们重新测量的。作者项目页含示意演示，作者明确说明不是实际模型推理录像。
