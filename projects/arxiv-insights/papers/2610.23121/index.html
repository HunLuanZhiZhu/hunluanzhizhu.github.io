第一层 · 问题直觉

五分钟看懂：为什么会摆家具，还不等于会设计？

要解决什么生成一个既不碰撞、又符合生活功能与布局美感的三维室内场景；还能少走弯路地纠错。
过去为什么难静态场景数据没有“改错过程”；通用模型会反复试错；几何规则能查碰撞，却难判断沙发与灯是否构成舒适阅读角。
关键变化先把有效施工轨迹和场景比较经验教给模型，再用冻结的评审器对候选动作排序、比较父子场景并反馈奖励。

把它想成一个有导师的室内设计实习生

原始训练只看完工照片，好比让学生背房间照片。本文增加两种学习材料：做事的过程（观察—思考—行动，简称 OTA）和评价的过程（观察—思考—评审，简称 OTC）。学生先模仿高效施工与评价，再在实际设计时试出四种下一步，由固定评审器给出排序和改进判断。

类比边界：真实系统不是人类设计师，不保证美学偏好或安全；评审器本身也是训练得到的视觉语言模型，可能存在偏差。

第二层 · 预备知识

读懂方法前，需要补的四块知识

一、视觉语言模型与工具调用：输入、输出是什么？

视觉语言模型（Vision-Language Model，VLM）把图像与文本一起作为条件，生成解释、决策或工具命令。本文输入是房间渲染图、当前状态摘要、上次执行反馈和设计要求；输出是推理文本与“放置/移动/旋转家具”等工具调用。工具真正改变三维场景后，再返回新图与碰撞等反馈。

二、轨迹、监督微调与因果精简

轨迹（Trajectory）是一串“观测→行动→环境反馈”。监督微调（Supervised Fine-Tuning，SFT）让模型模仿训练样本中的动作。本文不盲目保留所有失败重试，而是比较动作前后与最终状态的差异、错误数量，再借助模型判断操作是否对后续纠错有必要，删除可确认无用的步骤，最后通过回放确认终态一致。

三、偏好评审器与排序，不等于绝对真理

评审器（Critic）读取同一设计指令和多个场景图，给出由好到坏的次序。训练偏好通过不同程度的布局、功能与物理扰动构造。它提供的是相对质量判断，不是无误的现实物理仿真，也不是人类审美的统一标准。

四、组相对策略优化为什么需要“优势”

组相对策略优化（Group Relative Policy Optimization，GRPO）在相同条件下采样多个候选，把各自奖励与组平均相比，再推动策略更倾向于相对好的动作。优势（Advantage）表示“比同组平均好多少”，不是动作的绝对价值。本文另把整条轨迹的效率与物体完整度加入优势。

第三层 · 机制直觉

从两份训练经验，到会自我评审的设计策略

图中“场景构建器”经强化学习成为“场景设计师”；推理时可再次使用评审器筛选四条分支，但会增加候选执行与评价成本。

  1. 清洗过程：从原始工具轨迹中识别并谨慎删除无效尝试，保留必要中间状态，并回放核对终态。
  2. 学会评价：把轻度布局破坏、功能破坏、严重物理违规构成有序对照，训练同一个模型做场景排序。
  3. 训练策略：同一父场景采样四个动作，冻结评审器分别给出兄弟排名与父子改进信号。
  4. 推理选择：评审器可以在推理时从四个候选中选择更优分支；不是必须每步都只采样一次。

第四层 · 技术拆解

逐式核对：从轨迹精简到奖励与优势

以下 12 组为官方全文方法 §3.1、附录 B 与 C 的原式或明确标注的条件中文等价排版。每组都给出数学排版、LaTeX 核对源、完整符号解释和教学例子。复杂公式可在自己的区域左右滚动。

一、精简数据：删掉无效操作，但保留最终结果

公式 01方法 §3.1，公式 (1)
T′⊆T,S(T′)=S(T)

为什么要它：压缩工具操作序列，却要求回放后最终场景不变。

逐项符号词典：T 为原始操作轨迹；T′ 为按原顺序保留的子序列；⊆ 表示子序列操作来自原轨迹；S(·) 是将轨迹在环境中执行后得到最终场景状态的函数；等号表示最终状态相同。

直觉 / 例子：原来依次摆桌、反复移动、最后摆正；删除中间无效移动后，最终桌位仍一致。

核对原文 LaTeX 数学源
T'\subseteq T,\quad S(T')=S(T)
公式 02方法 §3.1，公式 (2)
Δistate=D(Si−1,Sf)−D(Si,Sf)

为什么要它：衡量第 i 步让当前场景向最终被接受场景靠近多少。

逐项符号词典：Δ 是变化量；上标 state 表示场景状态进展；i 是操作步序号（从 1 开始）；Sᵢ₋₁、Sᵢ 分别为操作前、后的场景状态；S_f 为最终接受的场景；D(·,·) 为根据物体位置和朝向计算的差异度；− 为差值。

直觉 / 例子：若到终态的差异从 8 降至 5，进展为 3；若从 8 升至 9，进展为 −1。数值为教学示例。

核对原文 LaTeX 数学源
\Delta_i^{\mathrm{state}}=D(S_{i-1},S_f)-D(S_i,S_f)
公式 03方法 §3.1，公式 (3)
Δierror=Vi−1−Vi

为什么要它：独立检查一步操作是否减少了剩余错误数。

逐项符号词典：Δ 为变化量；上标 error 表示错误减少量；i 是步骤编号；Vᵢ₋₁ 与 Vᵢ 是该步前后尚存错误的个数；减法为前值减后值，正数意味着纠错。

直觉 / 例子：门被家具挡住且窗被遮住共 2 处，移动柜子后剩 1 处，则错误减少量为 1。

核对原文 LaTeX 数学源
\Delta_i^{\mathrm{error}}=V_{i-1}-V_i

实现细节：候选删除操作必须同时满足规则筛查、因果核验器判为“无效尝试”、置信度至少 0.8；添加/删除物体等关键操作保守保留。回放检验与人工复核共同降低误删风险。原文附录 D.2 给出判别流程。

三、局部奖励：名次与真正改进是两个问题

公式 06附录 C.1，公式 (8)、(9)
rt,ilocal=rt,ifmt+rt,irank+rt,iimp

为什么要它：将动作合法性、兄弟分支排序和相对父场景改进合并为局部奖励。

逐项符号词典：r 为奖励标量；下标 t 是编辑步，下标 i 是同一父场景下第 i 个候选；local 为局部总奖励；fmt 为格式与工具调用合法性（有效时 1、无效时 0）；rank 为分支排序奖励；imp 为父子改进奖励；+ 表示直接相加，原文未在此式添加权重。

直觉 / 例子：合法动作获得 1，分支排序奖励 2/3，优于父场景获得 0.5，总局部奖励约 2.167。教学计算。

核对原文 LaTeX 数学源
r_{t,i}^{\mathrm{local}}=r_{t,i}^{\mathrm{fmt}}+r_{t,i}^{\mathrm{rank}}+r_{t,i}^{\mathrm{imp}}
公式 07附录 C.1，公式 (11)；页面将条件汉化排版，LaTeX 保留原式
rt,irank={−0.5无效分支|ℒt|−1−pt,i|ℒt|−1有效且至少两个1唯一有效分支

为什么要它：把评审器的名次转为可计算奖励，失败动作给负分。

逐项符号词典：r、t、i 与上一式相同；rank 为排序分量；ℒₜ 是第 t 轮满足几何约束且成功渲染的候选索引集合；|ℒₜ| 为有效分支数；pₜ,ᵢ 是第 i 个候选的零起始排名（最好为 0）；−0.5、1 是论文规定的固定奖励；分式按有效分支数量归一化。右侧中文条件对应原文 i∉ℒₜ、i∈ℒₜ 且 |ℒₜ|≥2、以及 |ℒₜ|=1 三种互斥情形。

直觉 / 例子：四个有效分支按 0、1、2、3 名次，对应奖励 1、2/3、1/3、0；无效分支为 −0.5。

四、全局奖励：效率与完整度的制衡

公式 09附录 C.2，公式 (15)
Rglen=clip(Yzero−YgYzero−Yfull,0,1)

为什么要它：完整场景不应通过无穷多轮试错完成；用截断线性奖励鼓励短轨迹。

逐项符号词典：R 为全轨迹奖励；下标 g 是第 g 条完整轨迹；上标 len 表示长度奖励；Y_g 是该轨迹实际交互步数；Y_zero=45 是奖励归零阈值；Y_full=25 是获得满分的目标步数；clip(x,0,1) 将数值限制在 0 与 1 之间；分母 45−25=20 为过渡区间。

直觉 / 例子：25 步及以下奖励 1；35 步奖励 0.5；45 步及以上奖励 0。参数取自论文训练配置。

核对原文 LaTeX 数学源
R_g^{\mathrm{len}}=\operatorname{clip}\!\left(\frac{Y_{\mathrm{zero}}-Y_g}{Y_{\mathrm{zero}}-Y_{\mathrm{full}}},0,1\right)
公式 10附录 C.2，公式 (16)
Rgobj=clip(ng−nzeronfull−nzero,0,1)

为什么要它：避免模型为了缩短轨迹，过早停止且只生成空房间。

逐项符号词典：R、g 与上一式相同；上标 obj 是物体完整度奖励；n_g 为最终场景中的物体数量；n_zero=10 为无奖励下限；n_full=25 为满分目标；clip(·,0,1) 是截断算子；0、1 为奖励区间边界。

直觉 / 例子：10 件及以下得 0；20 件得 2/3；25 件及以上得 1。只衡量数量，不能代替功能质量。

五、组内标准化与最终优势

为什么要它：把同一父场景的分支奖励标准化为相对优势，用于组相对策略优化。

直觉 / 例子：奖励高于组平均值则优势为正；四条分支奖励完全相同，分子为 0，不产生相对排序信号。

结论、限制与可复现性

作者证据支持什么

在论文所用场景构建框架与房型中，联合监督微调加评审器引导的强化学习提高多项房间质量指标；训练出的评审器在作者构造的偏好测试集上有更高排序准确率；额外推理时评审可进一步提升结果。研究呈现了“设计经验”和“评审经验”相互促进的证据。

尚不能推出什么

  • 评价独立性：视觉语义分数由 GPT-4 评定；训练偏好部分由扰动强度自动确定，部分由人工标注。与真实用户的审美和可用性不完全等价。
  • 外推范围：主要评估室内场景、特定工具脚手架和四种房型，不能直接推断到工业设计、开放世界物理或所有文化审美偏好。
  • 推理成本：每步四分支执行和评审会增加候选采样及工具调用；论文强调质量提升，但不能仅凭质量分数推断真实部署的延迟/成本收益。
  • 奖励代理偏差：按物体数量奖励完整度可能鼓励堆积家具；需要同时用功能、物理与布局约束抑制。
  • 可靠性：冻结评审器的排序不保证每次正确；分支奖励优化可能放大评审器的系统性偏好。
  • 复现资源边界：作者公开代码仓库目前说明，已公开的模型权重是强化学习之前的监督微调阶段；完整强化学习复现还需要外部场景工具、资产及环境配置，不能将“有代码”直接等同于完整端到端复现。
