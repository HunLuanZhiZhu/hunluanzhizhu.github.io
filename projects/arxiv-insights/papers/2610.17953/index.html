五分钟看懂：从“重试”到“真正修复”

传统工具智能体擅长在正常反馈中执行计划，却常把错误返回当成事实。论文主张：不只是让模型经历更多任务，而是让它学会识别失败模式，并将恢复策略写入模型参数。

一个具体场景

智能体准备读取日程，却收到「403：无权访问」。盲目重试十次不能修复权限；正确做法是识别为鉴权问题，检查授权状态，必要时向用户请求权限。

若用户说「不是周三，是周四」，正确动作也不是继续执行旧计划，而是重新约束任务目标、核对已产生的副作用。

这篇论文改变了什么？

用真实工具故障构造可验证的训练环境；从成功/失败轨迹对比提炼可复用的“反思技能”；再用监督学习与强化学习把技能内化。

这些是作者的设计和实验结果，不意味着模型已经在所有真实系统中安全可靠。

工具调用与轨迹：智能体到底在学习什么？

工具调用（Tool Calling）是模型根据当前对话和状态选择外部函数及参数，例如「查询订单」；工具返回可能成功，也可能超时、报错或包含误导信息。轨迹（Trajectory）是一次任务从请求、模型动作、工具返回到最终结果的完整序列。本文要学的不是单句答案，而是轨迹中出错后的决策。

监督微调与强化学习为什么要结合？

监督微调（Supervised Fine-Tuning，SFT）把经过验证的正确后续动作作为示范，让模型学习「遇到这种情形该怎么说、怎么做」。强化学习（Reinforcement Learning，RL）让当前模型自己尝试任务，依据任务验证器的结果更新策略；它能超出固定示范，但成功/失败的单一分数难以指出哪个决策错了。

策略、回报、优势、在线采样

策略（Policy）是模型在给定历史下选择下一个词元或动作的概率分布；回报（Return）由任务验证器提供。优势（Advantage）衡量某条轨迹相对同组轨迹的好坏。在线策略采样（On-Policy Rollout）指训练样本由当前或刚更新前的策略生成，避免只依赖陈旧示范。

蒸馏与特权信息：为什么训练时可以给提示？

蒸馏（Distillation）让学生策略接近教师的决策。这里教师不是另一个更大的模型：同一个模型在训练时额外看到环境反思技能卡，对学生已生成的相同动作词元重新评分；学生在部署时不需要技能卡。技能卡是训练时特权上下文，不是测试答案。

技术拆解：三阶段如何形成闭环

一、故障注入与元技能发现（RSD）

作者从 557 个工具服务主题构造有数据库、工具、单元测试和状态验证器的环境；在九套外部任务环境收集 177,700 条工具返回，其中 24,510 条是错误。将错误归为八种可操作故障家族，再按概率替换训练反馈（§3.1、附录D.2、表4）。

论文公式（1）· 每次工具返回的故障注入原生数学标记语言排版
ot+1train={J(ot+1)若注入ot+1否则,bt+1inj∼Bernoulli(pinj)

符号：t 是交互轮次，t+1 是下一次工具返回；o 是原始工具反馈；上标 train 表示训练时观察值；J 是按工具类型选择相容故障并替换反馈的操作；b 是取 0 或 1 的随机注入指示量；上标 inj 表示注入；Bernoulli 是一次二值随机试验；pinj 是单次返回被替换的概率。论文附录D.2设为 0.2。

核对原始 LaTeX 源
o_{t+1}^{\mathrm{train}}=\begin{cases}J(o_{t+1}),&b_{t+1}^{\mathrm{inj}}=1,\\o_{t+1},&b_{t+1}^{\mathrm{inj}}=0,\end{cases}\quad b_{t+1}^{\mathrm{inj}}\sim\mathrm{Bernoulli}(p_{\mathrm{inj}})

研究人员在同一任务上收集成功轨迹与失败轨迹，借助分析器定位首次错误动作、当时环境状态和失败原因，提炼成「什么现象触发 → 诊断哪类错误 → 如何恢复」的环境级技能卡。论文报告共 1,170 条技能，而非 1,170 个独立基准任务。

二、反思监督微调（ReSFT）

作者构造三类通过环境验证器筛选的训练样本：局部自反思（SR）从错误轮次恢复；全局技能恢复（KR）从初始任务重做；用户中心反思（UR）在上下文插入模拟用户纠正。SR 与 KR 在存储训练输入时移除特权技能卡，UR 保留真实部署时可见的用户纠正文本（§3.2，公式2—4）。

论文公式（5）· 监督数据合并与训练目标完整符号说明
𝒟ReSFT=𝒟correctπ0∪𝒟SR∪𝒟KR∪𝒟URℒReSFT=−∑(x,y)∈𝒟ReSFTlogπθ(y|x)

符号：𝒟 是数据集；下标 ReSFT 指本阶段汇总数据；correct 指原本已成功的轨迹；上标 π₀ 指由初始策略生成；SR/KR/UR 分别是局部自反思、全局恢复、用户纠正；∪ 表示并集；ℒ 是最小化的损失；∑ 表示对所有训练样本求和；(x,y) 是输入上下文与正确后续轨迹；∈ 表示属于；log 是自然对数；πθ(y|x) 是参数 θ 的策略在输入 x 下生成 y 的条件概率；− 使最大化正确示范概率转为最小化损失。

核对原始 LaTeX 源
\mathcal{D}_{\mathrm{ReSFT}}=\mathcal{D}_{\mathrm{correct}}^{\pi_0}\cup\mathcal{D}_{\mathrm{SR}}\cup\mathcal{D}_{\mathrm{KR}}\cup\mathcal{D}_{\mathrm{UR}}; \quad \mathcal{L}_{\mathrm{ReSFT}}=-\sum_{(x,y)\in\mathcal{D}_{\mathrm{ReSFT}}}\log\pi_\theta(y\mid x)

三、在线反思策略优化（ORPO）

第三阶段复用 EnvScaler 的约 2,500 项强化学习任务，而不是把第一阶段的 557 环境直接作为全部强化学习任务。当前策略在同一任务上生成一组干净/噪声混合轨迹，先按验证器回报训练，再对同一批已生成的动作词元增加技能指导的概率对比（§3.3、附录B.4）。

论文公式（6）· 组内优势标准化回报信号
μq=1G∑i=1GRq,i,σq2=1G∑i=1G(Rq,i−μq)2A^q,i=Rq,i−μqσq+ε

符号：q 是任务；i 是组内轨迹编号，范围 1 至 G；G 是同任务生成的轨迹数；Rq,i 是第 i 条轨迹的验证器回报；μq 是组均值；σ²q 是组方差，σq 是其非负平方根；Âq,i 是标准化优势；ε 是避免分母为零的小正数；求和符号表示遍历 G 条轨迹。

核对原始 LaTeX 源
\mu_q=\frac{1}{G}\sum_{i=1}^{G}R_{q,i},\quad\sigma_q^2=\frac{1}{G}\sum_{i=1}^{G}(R_{q,i}-\mu_q)^2,\quad\widehat A_{q,i}=\frac{R_{q,i}-\mu_q}{\sigma_q+\epsilon}
论文公式（10）· 技能提示带来的同词元概率变化蒸馏信号
Δq,i,t,k=sg[ℓq,i,t,kskill−ℓq,i,t,kθ]γq,i,t,k=sigmoid(βopdΔq,i,t,k)

符号：q、i 分别为任务与轨迹编号；t 是轨迹内动作轮次；k 是该轮生成词元的位置；ℓ 是相同动作词元的对数概率；上标 skill 是加入对应环境反思技能卡后的评分，上标 θ 是未加入技能卡的当前策略评分；Δ 是二者差值；sg 表示停止梯度，防止教师分支被反向传播修改；γ 是取值 0 到 1 的置信权重；βopd 是调节权重敏感度的正系数；sigmoid(z) 是将任意实数映射到 0—1 的函数。

核对原始 LaTeX 源
\Delta_{q,i,t,k}=\operatorname{sg}[\ell^{\mathrm{skill}}_{q,i,t,k}-\ell^\theta_{q,i,t,k}],\quad\gamma_{q,i,t,k}=\operatorname{sigmoid}(\beta_{\mathrm{opd}}\Delta_{q,i,t,k})
论文公式（11）（12）· 反思蒸馏与总损失优化目标
ℒOPD=𝔼[χγ(sg[ℓskill]−ℓθ)]ℒORPO=ℒRL+λopdℒOPD

第一行是论文（11）的紧凑教学记法，省略了每项重复的下标 q,i,t,k，其含义与上式一致。𝔼 是对采样任务、轨迹、轮次和词元求平均；χ 是有效智能体动作词元的 0/1 掩码，工具返回与模拟用户文本不参与梯度；γ 是公式（10）的权重；sg 为停止梯度；ℓskill 和 ℓθ 分别为带技能卡与不带技能卡的同词元对数概率。第二行中 ℒORPO 是总训练损失，ℒRL 是带裁剪概率比率和参考策略散度约束的强化学习损失（论文公式8），ℒOPD 是蒸馏损失，λopd 是平衡两项损失的非负系数。RL/OPD/ORPO 分别指强化学习、在线策略蒸馏、在线反思策略优化。

核对原始 LaTeX 源
\mathcal L_{\mathrm{OPD}}(\theta)=\mathbb E_{q,i,t,k}[\chi_{q,i,t,k}\gamma_{q,i,t,k}(\operatorname{sg}[\ell^{\mathrm{skill}}_{q,i,t,k}]-\ell^\theta_{q,i,t,k})];\quad \mathcal L_{\mathrm{ORPO}}=\mathcal L_{\mathrm{RL}}+\lambda_{\mathrm{opd}}\mathcal L_{\mathrm{OPD}}

重要区别：带技能卡的分支不额外生成轨迹，只是重新计算已经采样的同一词元概率。论文公式（7）—（9）给出普通策略概率、重要性比率与技能上下文的严格定义；公式（8）还包含裁剪目标和相对参考策略的散度正则。这里展示了影响机制理解的关键式，并标注了压缩表达的位置。

怎样正确解释这些数字？

作者报告，五项工具任务的总体得分从基础模型的 40.2 提升至 58.6；噪声基准总体得分为 29.1，而 EnvScaler 为 18.2。结果支持“反思训练在这套评测下有帮助”，但不能据此声称现实世界所有故障都能恢复。特别是部分基础模型与复现基线来自不同模型规模或评估来源，不宜直接解释成严格的同条件胜负。

局限与批判性阅读

作者明确承认：反思技能库来自固定时间点的离线环境快照；工具接口、服务行为和环境动态变化后，技能可能过时，需要重新挖掘或维护（附录F）。

本站进一步提醒：故障注入概率和八类错误家族无法覆盖所有真实世界失效；训练环境由合成工具与数据库构成；自动分析器与验证器可能带来系统性偏差。作者提供了环境族隔离、近重复检查和测试答案隔离措施（附录D.5），但这些是作者陈述，尚非本站独立审计。

复现入口：作者公开代码、训练数据与检查点。本页没有运行作者模型，也没有独立验证 58.6、29.1 等实验成绩。

读完应记住的三件事

一是“失败本身也能成为训练材料”。 同任务的成功与失败轨迹对比，能提供比单一成败奖励更具体的恢复策略。

二是“技能卡不等于部署时的提示词”。 技能卡主要在数据构建和训练期作为特权知识，目标是把反思行为内化到模型参数中。

三是“可靠性要在噪声下测量”。 正常环境成功率高，不代表能处理权限失败、错误返回或用户临时纠正。

一句话评价：这是一篇把环境级失败知识、验证过的恢复轨迹、同词元在线蒸馏串成训练闭环的研究；最有价值的不是“模型会自我批评”，而是把反思落实为可测量的后续动作。
